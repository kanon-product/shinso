# 深窓の猫

デスクトップで飼える、ちょっと喋る猫アプリです。

猫がデスクトップ上を歩いたり、休んだり、クリックに反応したりします。

## できること

- デスクトップ上を自由に歩く
- 座る・眠るなどの行動
- クリックすると反応
- 吹き出しでおしゃべり

## OpenAI API連携

OpenAI APIを設定することで、猫との自由な会話にも対応予定です。

API利用料は各利用者のOpenAIアカウントに発生します。
APIキーをアプリ本体やこのリポジトリに含めることはありません。

## 開発状況

現在開発中です。

まずはWindows向けの小さなデスクトップアプリとして公開予定です。
