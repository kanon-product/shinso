# 深窓

デスクトップにキャラクターを常駐させて、会話したり、散歩させたりできるWindows向けアプリです。

キャラクター画像や名前、性格、話し方などを変更して、自分好みにカスタマイズできます。

## できること

- デスクトップ上にキャラクターを表示
- 散歩・待機などの行動
- クリックへの反応
- 吹き出しでのおしゃべり
- キャラクター名・一人称・呼び方の変更
- 性格・話し方・敬語・返答の長さを設定
- キャラクター画像や会話パターンの差し替え

## OpenAI API連携について

本アプリの自由会話機能は、OpenAI APIとの連携を前提としています。

利用には、各自でOpenAI APIキーを設定する必要があります。

OpenAI APIの利用料は、各利用者のOpenAIアカウントに別途発生します。

APIキーをアプリ本体や、このリポジトリに含めることはありません。

API未設定時でも、一部の定型会話やキャラクター動作は利用できます。

## キャラクターのカスタマイズ

`Characters` フォルダ内の画像や設定ファイルを変更することで、
表示するキャラクターを差し替えることができます。

名前、性格、話し方などはアプリ内の設定画面から変更できます。
